Reescrita do Sistema James Fanstone

Reescrita do backend de uma plataforma institucional de pesquisa acadêmica, migrando do sistema legado em Laravel para Java e Spring Boot, hoje em produção.

  • Spring Boot 4

Ver em produção ↗

Contexto

O sistema institucional de pesquisa acadêmica da UniEVANGÉLICA (onde contribuí com features específicas, como relatórios de matrícula e edital, no sistema legado em Laravel) precisava evoluir para uma base mais sustentável, migrando o domínio de pesquisa para uma nova arquitetura.

Impacto

Reescrita incremental do backend em Java e Spring Boot: usuários e perfis com login multiperfil, permissões, auditoria, produção acadêmica (Qualis/CAPES e JCR), projetos com rascunho, anexos e aprovação, planos de trabalho com pontuação e importação de currículo Lattes via integração SOAP com o CNPq.

Stack

Java 21, Spring Boot 4, PostgreSQL com Flyway (26 migrações versionadas), Spring Security por sessão e cookie com RBAC, ArchUnit para regras de arquitetura, Swagger e CI no GitHub Actions. Actuator restrito a health e info após achado de auditoria.

Papel do Gabriel

Autor de todos os commits do repositório (83 de 83): arquitetura, modelagem de domínio, migrações, integração SOAP com o CNPq/Lattes e ADRs que guiam a migração incremental do legado.

Resultados

  • 31 controllers REST, 26 migrações Flyway e 482 testes aprovados na suíte registrada, em produção. A divisão entre arquivos unitários e de integração ainda não foi reconferida.
